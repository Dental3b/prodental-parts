# Pro Dental Repair – Parts

A simple Streamlit app that tracks dental parts orders for Pro Dental Repair in one table. Order data lives in `parts.csv`. Deploy it on [share.streamlit.io](https://share.streamlit.io) from the `main` branch with entrypoint `app.py`.

A second app, Pro Dental Repair – Equipment in Repair, tracks equipment brought back to the shop. Its data lives in `repairs.csv`, and its main file is `repairs.py`.
